📖 First-time Setup (Firestore backend)

1️⃣ Enable Firestore + Auth

In Firebase Console for your project: Firestore Database → Create database; Authentication → Email/Password → Enable. (Storage is not needed — no image uploads in this version, just paste hosted image URLs if you ever need one.)

2️⃣ Create your admin account

Authentication → Users → Add user. Use this email + password to sign in to this admin panel. Note the User UID shown — you'll need it for security rules.

3️⃣ Lock down Firestore rules

Firestore → Rules, paste (replace ADMIN_UID with your admin user's UID from step 2). Note exams is readable with no login required — the public landing page shows bundle pricing before anyone signs up:

rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /exams/{id}    { allow read: if true; allow write: if request.auth.uid == "ADMIN_UID"; }
    match /tests/{id}     { allow read: if request.auth != null; allow write: if request.auth.uid == "ADMIN_UID"; }
    match /sections/{id}  { allow read: if request.auth != null; allow write: if request.auth.uid == "ADMIN_UID"; }
    match /questions/{id} { allow read: if request.auth != null; allow write: if request.auth.uid == "ADMIN_UID"; }
    match /purchases/{id} { allow read: if request.auth.uid == "ADMIN_UID"; allow create: if request.auth != null; }
    match /users/{uid} {
      allow read, write: if request.auth.uid == uid;
      allow read, write: if request.auth.uid == "ADMIN_UID";
      match /attempts/{aid} { allow read, write: if request.auth.uid == uid; }
    }
    match /leaderboard/{tid}/entries/{uid} { allow read: if request.auth != null; allow write: if request.auth.uid == uid; }
  }
}

The users write rule now also allows your admin account — needed for the "Manually Grant Bundle Access" tool in the Exams tab, which writes to a student's user doc on your behalf.

4️⃣ Build content — one test at a time, or in bulk

Manual: use the tabs above in order: Exams / Bundles (one per exam, e.g. "10 mocks for ₹99") → Add Test (pick which exam it belongs to, or mark it Demo — you can also create the exam inline here via the "+ New" button) → Add Section → Add Question.

Bulk: use the Bulk Import tab to paste Markdown or upload a CSV and create a whole test — sections and all questions — in one step. See that tab for the exact format.

Use "Manage Tests" to edit, preview, or hide tests after creation.

📋 Full format reference
TEST_ID: id | NAME: .. | EXAM: exam_id | CATEGORY: .. | MINUTES: 60 | MODE: open|locked | DEMO: yes|noTest header — one line, required first
SECTION 1: Name | 25Q | 20min | +1/-0.25Starts a new section. Question count is auto-corrected to what's actually parsed.
Q1: question text…Standalone MCQ. Text can span multiple lines until the next token.
Q2 [GROUP:RC1|Passage I]: …Passage/puzzle question. Same GROUP id links questions to one passage.
PASSAGE: text…Passage text — put it once on the first question of a group.
Q5 [DESC:essay|250]: …Descriptive question. Types: essay, letter, paragraph. Number = word limit.
A) .. B) .. C) .. D) .. E) ..Options, one per line. E is optional (4 or 5 options both fine).
ANSWER: BCorrect option letter (skip for descriptive)
EXPLAIN: text…Optional explanation
QIMG: url / PASSAGEIMG: url / EXPIMG: urlOptional hosted image URLs
KEYPOINTS: point 1 | point 2 / OPENING: textDescriptive-only hints

Header row required, columns (case-insensitive): test_id, test_name, exam_id, category, total_minutes, mode, demo, section_id, section_name, num_q, time_min, marks_c, marks_n, qno, type, group_id, group_title, passage_text, question_text, question_image_url, passage_image_url, option_a, option_b, option_c, option_d, option_e, correct, explanation, explanation_image_url. test_id/test_name/exam_id/etc. just repeat on every row.

🔥 Firebase Config

Same project, same config, everywhere

This admin panel, the student portal (app.html), the public landing page (index.html), Firestore (tests/sections/questions/exams/users/purchases/attempts/leaderboard) must all point at the same Firebase project. Copy the firebaseConfig object from Project Settings → General → Your apps → Web, and paste the identical values into the top of this file, app.html, and index.html.

Student accounts

Students self-register in the student portal (app.html) via email/password. Your own admin account (used to sign into this panel) is separate — create it once via Authentication → Users → Add user, per the Setup Guide tab.
